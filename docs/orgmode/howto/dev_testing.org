* Problem

You want to run tests and check coverage across all optional dependency sets.

* Quick Start

** Single Environment (uv)

For basic development:

#+BEGIN_SRC shell
cd rgpycrumbs
uv sync --extra test
uv run pytest tests/ -m pure
#+END_SRC

** Full Coverage (pixi)

pixi manages multiple environments with different optional deps:

#+BEGIN_SRC shell
pixi run cov
#+END_SRC

This runs:

| Environment | Deps | Test marker | Covers |
|-------------+------+-------------+--------|
| test | numpy, scipy, ase, click | pure, eon | CLI, parsers, basetypes, interpolation |
| surfaces | + jax | surfaces | Surface models, kernels, gradient-enhanced GP |
| fragments | + IRA, tblite, pyvista | fragments, ira, align | Geometry analysis, IRA alignment, fragments |
| eonmlflow | + eon, mlflow | eon | MLflow logging of eOn runs and configs |
| ptm | + ovito | ptm | Polyhedral template matching, ~ovito~ rendering |

Each env writes ~COVERAGE_FILE=.coverage.<env>~, then ~cov~ combines them all.
A failing test in any environment stops ~cov~ with the pytest exit status.

** Individual Environments

#+BEGIN_SRC shell
pixi run -e test test-base          # base tests
pixi run -e surfaces test-surfaces  # jax surface models
pixi run -e fragments test-fragments # IRA + geometry
pixi run -e eonmlflow test-eonmlflow # eon + mlflow
pixi run -e ptm test-ptm            # ovito structure analysis
#+END_SRC

The version constraint in ~pixi.toml~ is ~>=3.16.0, <4~, and ~pixi.lock~ pins 3.17.2 for Python 3.13.

[[[end]]]

The comment above ~ovito~ in ~pixi.toml~ gives the basis for that constraint.
The ~ovito~ package on conda-forge is a retired OVITO Basic desktop build without the Python module.
With that package, every ~ptm~ test skips.

* How It Works

#+BEGIN_SRC dot :file coverage_flow.png
digraph coverage_flow {
    fontname="Jost"; fontsize=12;
    node [fontname="Jost", fontsize=12, shape=box, style=filled, fillcolor=white];

    clean [label="cov-clean\nremove .coverage.*", fillcolor="#F1DB4B"];
    test [label="test-base\n(numpy, scipy, ase)"];
    surfaces [label="test-surfaces\n(+ jax)"];

    report [label="coverage report", fillcolor="#004D40", fontcolor=white];

    clean -> test -> combine;
    clean -> surfaces -> combine;
    clean -> fragments -> combine;
    clean -> eonmlflow -> combine;
    clean -> ptm -> combine;
    combine -> report;
}

* Quality Guidelines

- New modules must have tests in the same PR
- Plot functions: at least smoke tests
- Parsers: synthetic input + output schema validation
- Pixi-only or heavyweight deps (IRA, tblite, pyvista, ovito): tested in their dedicated envs, not mocked
