==============
#+end_export

This table links each public module of ~rgpycrumbs~ to its page in the API reference, which AutoAPI builds from the docstrings.
Modules whose names start with =_= are internal, and the table leaves them out.
The [[file:../tutorials/module-atlas.org][module atlas]] describes the subpackages and shows which modules a notebook can import.

~rgpycrumbs.search~, ~rgpycrumbs.time~ and ~rgpycrumbs.orca~ have no =__init__.py=, so AutoAPI files their modules under bare names.
The page for ~rgpycrumbs.search.helpers~ is =helpers=, and ~rgpycrumbs.time.helpers~ has no page, because its name collides with that one.
