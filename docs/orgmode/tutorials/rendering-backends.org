#+begin_export rst
==================
Rendering backends
==================
#+end_export

~plt-neb~, ~plt-min~ and ~plt-saddle~ draw strips of structures under their plots, and =--strip-renderer= picks one of four backends for those structures.
This page describes the backends and the strip options that the three commands share.
The facts on this page come from ~xyzrender~ 0.2.3, ASE 3.28, ~solvis-tools~ 0.1.5 and ~ovito~ 3.17.2.

* Comparison

| Backend | Structures | Needs |
|---------+------------+-------|
| =xyzrender=, the default | Ball-and-stick, turned by principal component analysis (PCA) | The ~xyzrender~ Python package |
| =ase= | Spheres without bonds | Nothing beyond the plot commands |
| =solvis= | Ball-and-stick through PyVista | ~solvis-tools~ and the Xvfb display server |
| =ovito= | Spheres without bonds, inside the simulation cell | The ~ovito~ Python module and a Vulkan driver |

* xyzrender

The strips call ~xyzrender.render~, the Python function of [[https://github.com/aligfellow/xyzrender][xyzrender]], with hydrogens shown and a transparent background.
They do not need the =xyzrender= command on =PATH=.
If the package is missing and =RGPYCRUMBS_AUTO_DEPS= is on, ~ensure_import~ installs it into the uv cache, and the library plot functions turn that variable on by default.

With the default =--rotation auto=, xyzrender turns each structure by PCA, so that the structure spreads most across the image and least along the line of sight.
Any other value, such as =--rotation "0x,90y,0z"=, turns that off and rotates the atoms by the given angles about x, y and z, in that order.

=--xyzrender-config= picks the preset, =paton= by default.
In ~xyzrender~ 0.2.3, the presets differ from =default= as follows.

| Preset | Look |
|--------+------|
| =default= | Shaded atoms with outlines, depth fog and bond orders |
| =paton= | Thinner atom outlines, lighter fog and no bond orders |
| =flat= | No shading |
| =bubble= | Large atoms and no bonds |
| =tube= | Thick bonds colored by element, without atoms |
| =wire= | As =tube=, with thin bonds |
| =skeletal= | Skeletal formula |

Bond orders, non-covalent interactions (NCI) and van der Waals spheres belong to the =xyzrender= command, not to the strips.
To draw them for one structure, give the command an =.xyz= file, as in these two examples.

#+begin_src bash
xyzrender sp.xyz -o nci.png --config paton --hy --bo --nci
xyzrender sp.xyz -o vdw.png --vdw
#+end_src

** Bonds that change

The positions in a strip do not show which bonds form or break.
~rgpycrumbs chemgp plot-reactions~ computes GFN2-xTB single points at the stored geometries, with the charge and multiplicity from its profile file, and draws the Wiberg bond orders with xyzrender.
Its output keeps each of these calculations.
[[file:../tools/chemgp/method_comparisons.org][Method costs and reaction chemistry]] describes the command.

* ASE

The =ase= backend writes each structure to an image with ~ase.io.write~, as spheres without bonds and without the cell.
The plot commands already need ASE, so this backend needs nothing more.
ASE does not turn the structures by itself: =--rotation auto= gives the side view =0x,90y,0z=, and any other value passes to ASE as it is.

* solvis

The =solvis= backend draws atoms as spheres and bonds as cylinders with [[https://github.com/amritagos/solvis][solvis]], which renders through PyVista.
It draws a bond between two atoms closer than 1.1 times the sum of their covalent radii, and colors the atoms with the Jmol colors of ASE.
The background is transparent.
PyVista renders off-screen through Xvfb, so the Xvfb server must be installed.
=--rotation= works as for ASE.

* ovito

The =ovito= backend renders each structure with the Open Visualization Tool (OVITO) Python module, in an orthographic view on a white background.
It draws the atoms as spheres without bonds, together with the simulation cell, and zooms to fit the cell.
In the Diels-Alder files, the cell is a box of 25 Å, and the molecule spans at most 22% of the height and 15% of the width of each panel.
=--rotation= works as for ASE.

The conda-forge ~ovito~ package in the pixi environments of this repository has no Python module, so the backend stops there with =ovito not installed=.
In a plain virtual environment, ~pip install ovito~ installs ~ovito~ 3.17.2 with PySide6 and shiboken6, which take 505 MB together.
That version renders through Vulkan.
The strip renders with the Mesa Vulkan driver, and stops with =Could not initialize the Vulkan graphics backend= when no driver loads.

* Strip options

~plt-neb~, ~plt-min~ and ~plt-saddle~ take these options from one shared definition.

| Option | Default | Effect |
|--------+---------+--------|
| =--strip-renderer= | =xyzrender= | Backend for the structures |
| =--xyzrender-config= | =paton= | xyzrender preset |
| =--rotation= | =auto= | =auto=, or angles such as =0x,90y,0z= for every backend |
| =--perspective-tilt= | =0.0= | Tilt in degrees about a fixed line in the x-y plane, before rendering, so that hidden atoms come into view |
| =--strip-spacing= | =1.5= | Horizontal spacing between the structure images |
| =--strip-dividers= | off | Vertical lines between the images |
