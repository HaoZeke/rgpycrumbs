This tutorial reads one nudged elastic band (NEB) in Python, prints its barrier, fits a smooth profile to it and draws the profile figure.
It uses the Diels-Alder band of the [[file:neb-visualization.org][NEB visualization tutorial]], which draws the same data from the command line.

* Set up

#+begin_src bash
git clone https://github.com/HaoZeke/rgpycrumbs
cd rgpycrumbs
pixi shell -e fragments
cd docs/orgmode/tutorials
#+end_src

The =fragments= environment has ~numpy~, ~scipy~, ~jax~ and ~chemparseplot~, which the code on this page imports.
Run the code blocks in one Python session, in the order of the page.

* Read the band

The data folder has four =neb_NNN.dat= files from eOn, one for each of four snapshots of the band, and the last snapshot is =neb_014.dat=.
Its columns are the image index, the path length in Å, the energy in eV relative to image 0, and the force along the path in eV/Å.

#+begin_src python
import numpy as np

_, s, energy, f_para = np.loadtxt("data/diels_alder/neb_014.dat", skiprows=1, unpack=True)
top = int(np.argmax(energy))
print(f"{energy.size} images, highest at image {top}")
print(f"barrier {energy[top]:.3f} eV at {s[top]:.3f} Å")
print(f"reaction energy {energy[-1]:.3f} eV")
#+end_src

#+begin_example
22 images, highest at image 14
barrier 0.788 eV at 3.720 Å
reaction energy -1.948 eV
#+end_example

* Fit a profile

~get_surface_model~ returns a surface class by name, and ="matern"= fits a Gaussian process with a Matérn 5/2 kernel to the energies of the images.
~minimize_scalar~ then looks for the maximum of the fit.

#+begin_src python
from scipy.optimize import minimize_scalar

from rgpycrumbs.surfaces import get_surface_model

model = get_surface_model("matern")(s[:, None], energy)
peak = minimize_scalar(
    lambda x: -float(model(np.array([[x]]))[0]),
    bounds=(s[top - 1], s[top + 1]),
    method="bounded",
)
print(f"fitted maximum {-peak.fun:.3f} eV at {peak.x:.3f} Å")
#+end_src

#+begin_example
fitted maximum 0.789 eV at 3.787 Å
#+end_example

The search for the maximum stays between the two neighbors of the highest image.
The fit passes through the images, and its maximum lies 0.002 eV above image 14 and 0.067 Å further along the path.
The gradient-enhanced types, such as ="grad_matern"=, also take the force along the path, as =gradients=-f_para[:, None]=.
On this band, the five gradient-enhanced types miss the energy of image 15, just past the peak, by 0.10 to 0.14 eV.

* Draw the profile

#+begin_src python
from rgpycrumbs.eon import plot_neb

plot_neb(
    plot_type="profile",
    input_dat_pattern="data/diels_alder/neb_*.dat",
    input_path_pattern="data/diels_alder/neb_path_*.con",
    con_file="data/diels_alder/neb.con",
    sp_file="data/diels_alder/sp.con",
    output_file="profile.png",
)
#+end_src

~plot_neb~ takes the options of ~rgpycrumbs eon plt-neb~ as keywords, with =_= in place of =-=.
It logs the files that it reads, and writes the same figure as the first command of the NEB visualization tutorial.
