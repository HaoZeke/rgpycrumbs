#+TITLE: NEB reaction path visualization
#+AUTHOR: Rohit Goswami
#+OPTIONS: toc:nil todo:nil num:nil author:nil

This tutorial plots one nudged elastic band (NEB) calculation with ~rgpycrumbs eon plt-neb~.
The reaction is a Diels-Alder cycloaddition, in which 1,3-butadiene and ethylene form cyclohexene.
Each figure comes from the command printed above it.

The two-dimensional maps in this tutorial follow R. Goswami, "Two-dimensional RMSD projections for reaction path visualization and validation", /MethodsX/ (2026), [[https://doi.org/10.1016/j.mex.2026.103851][doi:10.1016/j.mex.2026.103851]].
Please cite that paper if you use these maps in published figures.

* Data and environment

The eOn output files for this tutorial are in =docs/orgmode/tutorials/data/diels_alder/=.
The system is C6H10 with 16 atoms, and each band has 22 images.
eOn computed the band with its metatomic potential interface.

| File | Content |
|------+---------|
| =neb_000.dat=, =neb_005.dat=, =neb_010.dat=, =neb_014.dat= | Four snapshots of the band during the optimization, with =neb_014.dat= as the last |
| =neb_path_000.con= to =neb_path_014.con= | Structures for the same four snapshots |
| =neb.con= | Structures of the final band |
| =sp.con= | Saddle point structure |

Each =.dat= file lists the image index, the path length, the energy relative to image 0 and the force along the path.
The =.con= files store the atom positions of the same images.

The maps compare the structures of the images through Iterative Rotations and Assignments (IRA), which aligns two structures and matches their atoms.
The repository's pixi =fragments= environment provides IRA, and the figures on this page come from that environment.
Run the commands from the tutorial folder.

#+begin_src bash
git clone https://github.com/HaoZeke/rgpycrumbs
cd rgpycrumbs
pixi shell -e fragments
cd docs/orgmode/tutorials
#+end_src

Outside pixi, install IRA from conda-forge, where the package is named =ira=.
Without IRA, the maps can differ from the ones shown here, because ~plt-neb~ then aligns structures in the atom order of the files.

* Energy profile

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type profile \
  --input-dat-pattern "data/diels_alder/neb_*.dat" \
  --input-path-pattern "data/diels_alder/neb_path_*.con" \
  --con-file data/diels_alder/neb.con --sp-file data/diels_alder/sp.con \
  -o profile.png
#+end_src

#+begin_export rst
.. image:: /_static/tutorial/profile.png
   :alt: Energy against path length for four snapshots of the band. The black final band peaks near 0.8 eV at the saddle point star and ends near minus 1.9 eV.
#+end_export

Each curve shows one snapshot of the band, and the black curve shows the final band.
The default =--spline-method hermite= joins the images with cubic Hermite splines, which take the slope at each image from the force along the path.
In the final band, image 14 sits 0.788 eV above image 0, and the product lies 1.948 eV below image 0.
The star marks the saddle point from =sp.con=.

* Reaction valley maps

** Distances from the reactant and the product

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type landscape --landscape-mode path --no-project-path \
  --input-dat-pattern "data/diels_alder/neb_*.dat" \
  --input-path-pattern "data/diels_alder/neb_path_*.con" \
  --con-file data/diels_alder/neb.con --sp-file data/diels_alder/sp.con \
  -o landscape_raw.png
#+end_src

#+begin_export rst
.. image:: /_static/tutorial/landscape_raw.png
   :alt: The final band drawn on axes of root mean square deviation from the reactant and from the product, colored by energy, over a shaded background.
#+end_export

Each image becomes a point at its root mean square deviation (RMSD) from the reactant and from the product.
The shaded background interpolates the energies of the images in all four snapshots, so it covers only the region that the bands visited.

Images 2 and 3 sit further from the product than image 1 does.
For these two images, IRA matches the atoms to the product in a different order from the one in the files.
That order gives RMSD values of 1.232 Å and 1.142 Å, against 0.928 Å and 0.881 Å in file order.

** Progress and deviation coordinates

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type landscape --landscape-mode path --project-path \
  --input-dat-pattern "data/diels_alder/neb_*.dat" \
  --input-path-pattern "data/diels_alder/neb_path_*.con" \
  --con-file data/diels_alder/neb.con --sp-file data/diels_alder/sp.con \
  -o landscape_projected.png
#+end_src

#+begin_export rst
.. image:: /_static/tutorial/landscape_projected.png
   :alt: The same band after rotation into reaction progress s along the horizontal axis and orthogonal deviation d along the vertical axis.
#+end_export

The =--project-path= flag rotates the RMSD plane.
The horizontal coordinate /s/ then measures progress along the line from the reactant to the product, and the vertical coordinate /d/ is the distance from that line.
A band that stays near /d/ = 0 follows the direct line between the end points.

** Fitted surface

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type landscape --landscape-mode surface \
  --surface-type grad_matern --project-path \
  --input-dat-pattern "data/diels_alder/neb_*.dat" \
  --input-path-pattern "data/diels_alder/neb_path_*.con" \
  --con-file data/diels_alder/neb.con --sp-file data/diels_alder/sp.con \
  -o surface_projected.png
#+end_src

#+begin_export rst
.. image:: /_static/tutorial/surface_projected.png
   :alt: A fitted energy surface on the progress and deviation axes, with dashed variance contours and the final band on top.
#+end_export

The =--landscape-mode surface= option fits a surface to the images of all four snapshots and draws the final band on top.
With =--surface-type grad_matern=, the surface is a Gaussian process (GP) with a gradient-enhanced Matérn kernel.
The default =rbf= fits a thin-plate spline to the energies alone.
The gradients come from the force along the path, projected onto the direction of the band in the map.
Dashed contours mark levels of the GP variance.

On this band the fit does not follow the energies.
The fitted surface spans only -0.31 eV to 0.31 eV over the map, while the images of the final band run from -1.95 eV to 0.79 eV.
The background therefore shows no barrier, only a slope from the reactant side down to the product side.
Its colors also span the range of the fitted surface, and not the range on the colorbar, which belongs to the band.
Read the energies from the colors of the band.

* Structure strips

The =--plot-structures crit_points= option draws three structures under the plot: the reactant, the highest image and the product, labeled R, SP and P.
The =--strip-renderer= option picks the program that draws them.

- =xyzrender= is the default.
  It draws ball-and-stick models, and its default =--rotation auto= orients each molecule from a principal component analysis of its atom positions.
- =ase= needs no extra package and draws each structure with space-filling spheres.
- =solvis= renders ball-and-stick models through PyVista, which needs a display.
- =ovito= uses the Open Visualization Tool (OVITO), a separate install.

The other three renderers draw each molecule in the fixed side view =0x,90y,0z= unless =--rotation= names another one.
The =--strip-dividers= flag draws dashed lines between the panels.

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type profile --plot-structures crit_points --strip-dividers \
  --strip-renderer xyzrender \
  --input-dat-pattern "data/diels_alder/neb_*.dat" \
  --input-path-pattern "data/diels_alder/neb_path_*.con" \
  --con-file data/diels_alder/neb.con --sp-file data/diels_alder/sp.con \
  -o gallery_xyzrender.png
#+end_src

#+begin_export rst

   :alt: The energy profile with ball-and-stick structures of the reactant, the highest image and the product drawn by xyzrender below it.
#+end_export

The structures still differ, because the two forming C-C bonds shrink from 3.93 Å and 3.45 Å in R to 2.63 Å and 2.03 Å in SP, and both reach 1.53 Å in P.

The =--rotation= option takes an ASE rotation string such as ="45x,30y,0z"= for every renderer.
The =--perspective-tilt= option can uncover atoms hidden behind others, because it turns each structure by the given number of degrees about a direction in the picture plane.

* Refinement overlay

The =--mmf-peaks= flag overlays the frames of a minimum-mode following (MMF) refinement on a landscape plot.
It reads the =climb= or =climb.con= movie that eOn writes into the folder named by =--peak-dir=, which defaults to the current folder.
Without either flag, the overlay turns on whenever that folder contains such a movie, and =--no-mmf-peaks= turns it off.
The Diels-Alder data has no climb movie, so this page shows no overlay.

* Option summary

| Option | Effect |
|--------+--------|
| =--plot-type profile= | Energy against path length |
| =--plot-type landscape --landscape-mode path= | Bands on the RMSD map |
| =--landscape-mode surface= | Fitted surface behind the final band |
| =--project-path= | Progress and deviation coordinates |
| =--plot-structures crit_points= | Strip with the reactant, the highest image and the product |
| =--strip-renderer= | Program that draws the strip |
| =--show-evolution= | Earlier snapshots as faint lines |
| =--mmf-peaks= | Refinement frames from a climb movie |
