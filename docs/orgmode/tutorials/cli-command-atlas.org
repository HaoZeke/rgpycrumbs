=============
Command atlas
=============
#+end_export

The dispatcher turns the modules of each subpackage into commands of the form =rgpycrumbs GROUP COMMAND=.
The group is the name of the subpackage, and the command is the name of the module with each =_= turned into =-=, so =rgpycrumbs/eon/plt_neb.py= becomes =rgpycrumbs eon plt-neb=.
The dispatcher leaves out modules whose names start with =_=, and the library modules =hdf5_io=, =plotting=, =utils=, =helpers= and =seed_dimers=.

* Check a command

The dispatcher passes =--help= on to the module.
A command script answers with its options.

#+begin_src bash
rgpycrumbs eon plt-neb --help
#+end_src

The sections below give the result of that check for each of the 51 commands, run with ~rgpycrumbs~ 1.13.0 in the =fragments= environment of the pixi workspace.

* Command scripts

A command script carries a [[https://peps.python.org/pep-0723/][Python Enhancement Proposal (PEP) 723]] header with its dependencies.
32 of the 35 scripts print their options.

| =uma=       | =aoti-cache=, =prepare-aoti=                                                                                                                                             |

The other three scripts need more than the =fragments= environment gives them:

- =eon to-mlflow= imports ~mlflow~, and works in the =eonmlflow= environment.
- =eon ptmdisp= imports the Python module of ~ovito~, which the conda-forge package in the =ptm= environment lacks, and prints its options with the PyPI wheel of ~ovito~ 3.17.2.
- =plumed direct-reconstruction= takes no options.
  It reads a file named =HILLS= from the working directory, and without one it stops with an error.

* Library modules
