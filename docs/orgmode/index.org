* Overview

~rgpycrumbs~ is a library and command-line toolkit for chemical physics.
It fits surfaces to energy landscapes with ~jax~, compares structures through Iterative Rotations and Assignments (IRA), and detects the fragments of a structure.
Its commands plot nudged elastic band (NEB) paths, saddle searches and minimizations, and set up simulations.

~rgpycrumbs~ has two sister libraries for the other ends of a simulation.
[[https://pychum.rgoswami.me][pychum]] writes the input files, and [[https://chemparseplot.rgoswami.me][chemparseplot]] parses structures and energies from the output and draws the plots.
The *Ecosystem* menu in the header of every page links the three sites.

Start with the [[file:quickstart.org][quickstart]] or the [[file:tutorials/neb-visualization.org][NEB visualization tutorial]].

* Features

- *Nudged elastic band plots* :: Energy profiles along the band, and maps of the reaction valley in two coordinates under a surface fit to the band ([[file:tutorials/neb-visualization.org][tutorial]]).
- *Structure strips* :: Four renderers draw the structures at the critical points: ~xyzrender~, ~ase~, ~solvis~ and ~ovito~.
- *Overlays* :: The frames of a minimum-mode following refinement, and the earlier snapshots of the band.
- *Single-ended methods* :: The same maps for saddle searches with the dimer method and for minimizations.
- *Surface fitting* :: Gaussian process fits in ~jax~ to energies and gradients, with Matérn, inverse multiquadric (IMQ), rational quadratic and squared exponential kernels, and fits to energies alone with a thin-plate spline or the Matérn and IMQ kernels.
- *Structure analysis* :: Matching and alignment of structures by IRA, fragment detection from covalent radii or GFN2-xTB bond orders, and distance matrices.
- *Simulation setup* :: ~eon generate-nwchem-input~ and ~orca generate-orca-input~ write input files for those two programs, and ~eon gen-dimer~ seeds eOn saddle searches from the peaks of a band.
- *Command dispatcher* :: The dispatcher turns the scripts of the package into commands, and a script with a [[https://peps.python.org/pep-0723/][Python Enhancement Proposal (PEP) 723]] header lists its dependencies there.
- *Dependency resolution* :: If the active Python has the eOn plotting libraries, the dispatcher runs the command there, and otherwise through ~uv run --script~, which installs the dependencies from the header.
