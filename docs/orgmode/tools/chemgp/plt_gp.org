* Overview

~rgpycrumbs chemgp plot-gp~ draws figures from ChemGP output in HDF5 files, through ~chemparseplot~.
ChemGP is the Rust crate ~chemgp-core~, and its examples write these files.
Each subcommand draws one kind of figure:

| Subcommand | Figure |
|------------+--------|
| =convergence= | Force or energy against oracle calls, on a log scale |
| =surface= | Filled contours of a two-dimensional potential energy surface, with optional paths and points |
| =quality= | Panels of the Gaussian process mean at growing training sizes |
| =rff= | Energy and gradient errors of random Fourier features against their dimension |
| =nll= | Contours of the negative log-likelihood over two log hyperparameters |
| =sensitivity= | Grid of one-dimensional Gaussian process slices with confidence bands |
| =trust= | Trust region on a one-dimensional slice |
| =variance= | Potential energy surface with its high-variance regions hatched |
| =fps= | Principal component scatter of the points that farthest point sampling keeps |
| =profile= | Nudged elastic band energy profile against image index |
| =batch= | Every figure of one plot list |

* Common options

Every subcommand except =batch= takes:

- =--input= / =-i= :: the HDF5 file, required
- =--output= / =-o= :: the output file, required
- =--width= / =-W= and =--height= / =-H= :: figure size in inches, 7.0 by 5.0 by default
- =--dpi= :: resolution in dots per inch, 300 by default

* Usage

#+begin_src bash
rgpycrumbs chemgp plot-gp convergence -i output/leps_minimize.h5 -o convergence.pdf
rgpycrumbs chemgp plot-gp surface -i output/leps_neb.h5 -o surface.pdf
rgpycrumbs chemgp plot-gp nll -i output/leps_nll.h5 -o nll.pdf
#+end_src

* Batch mode

=batch= reads a list of figures from a file in Tom's Obvious, Minimal Language (TOML), with one =[[plots]]= table for each figure:

#+begin_src toml
[[plots]]
type = "convergence"
input = "leps_minimize.h5"
output = "convergence.pdf"
#+end_src

#+begin_src bash
rgpycrumbs chemgp plot-gp batch --config figures.toml
#+end_src

Each table names its subcommand in =type=.
Its other keys pass on as options of that subcommand, so =clamp_lo = -5.0= turns into =--clamp-lo -5.0=.
With click 8.3.1, the version in the pixi environments, every entry fails with =CliRunner.__init__() got an unexpected keyword argument 'mix_stderr'=, and the batch exits with status 1.
Until that changes, run the subcommands one at a time.
The @@rst::doc:`batch tutorial <batch_tutorial>`@@ works through a longer plot list.

* Energy clamping

=surface=, =quality= and =variance= clip the energy range by the name of the input file.
A name that contains =mb= gets the range from -200 to 50, and a name that contains =leps= gets -5 to 5.
For other names, =quality= and =variance= fall back to -200 to 50, while =surface= leaves the range open.
=surface= also takes =--clamp-lo= and =--clamp-hi=, and with either of them the file name no longer sets the range.
