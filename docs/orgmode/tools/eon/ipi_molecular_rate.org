#+title: i-PI molecular instanton rate

The instanton and reactant calculators in i-PI report separate partition
functions. This command combines their native postprocessing tables to
give the absolute rate for one reaction path in a nonlinear gas-phase
molecule. Report both states at the same temperature and full bead count,
use the =poly= rigid-mode projection, and specify the reactant electronic
energy as the instanton energy shift.

#+begin_src shell
rgpycrumbs eon ipi-molecular-rate reactant.out instanton.out
#+end_src

The JSON includes =log10_rate_per_s=, the rotational and translational
ratios, the dimensionless Euclidean action and the vibrational partition
terms. i-PI's instanton table includes the factor of bead count in the
printed vibrational partition. The calculation combines that quantity
with the reactant finite-bead partition and the orbit length factor,
following the [[https://atomistic-cookbook.org/examples/ring-polymer-instanton/rpi-rates.html][i-PI rate tutorial]].
The native tables print three decimal places. Equivalent reaction paths
increase the total rate by their multiplicity.

For a stored i-PI half-ring, =eon orbit-residual --ipi-half-ring= reflects
the beads through the turning points and checks the discrete spring force.
It requests independent forces only at the stored beads.

The solver's own gradient ledger provides a separate check. Supply its
converged half-ring in readcon format and the JSON-lines trace containing
the original Cartesian coordinates and gradients. The command below also
checks the printed i-PI FINAL coordinate and atomic-unit force tables
from the run directory and saves the selected requests in bead order.

#+begin_src shell
rgpycrumbs eon ipi-orbit-observations ring.con evaluations.jsonl \
    --native-directory . --write-observations matched.jsonl
#+end_src

The JSON reports the finite-bead and Fourier force residuals in eV/Å, the
original solver request number for each bead, and the maximum force and
coordinate differences from i-PI's printed step. Matching requires identical
binary64 geometry coordinates. It performs zero new potential evaluations.

Adding =--initial-xyz init.xyz= compares the first measured gradient batch
with the converged orbit at the same temperature and bead count. The report
includes the initial force residuals, the RMS change in interatomic distances
over the stored half-ring and the bead and atom pair with the largest change.

The molecular rate omits the second nonrigid fluctuation mode to account
for translation around the imaginary-time orbit. To identify the omitted
mode, supply the converged checkpoint, native instanton frequencies
and native instanton output from the same run.

#+begin_src shell
rgpycrumbs eon ipi-phase-mode RESTART native/instanton/freq.dat native/instanton.out
#+end_src

The command rebuilds the native mass-weighted fluctuation matrix from
stored bead Hessians at the temperature printed in the native output.
It compares the full spectrum and projects the mass-weighted Fourier
derivative of the orbit onto the eigenvectors. The JSON identifies the
largest absolute overlap, the signed frequency omitted from the native
partition and the number of retained unstable modes. A near-unit overlap
at the omitted index identifies the phase mode even when its finite-grid
frequency is negative. The check requires no new force evaluations.
