* Nudged elastic band paths and landscapes

~plt-neb~ plots the output of a nudged elastic band (NEB) calculation from eOn.
A profile plot draws the energy of the images along the path, one curve for each =neb_*.dat= file.
A landscape plot places the images on a plane of structural distances from the reactant and the product, over a surface fitted to their energies.
Either plot can carry a strip of rendered structures.

* Landscape coordinates

Each image becomes a point at its root mean square deviation (RMSD) from the reactant and from the product.
Iterative Rotations and Assignments (IRA) aligns each pair of structures and matches their atoms before the RMSD.
By default, ~plt-neb~ rotates this plane into a progress coordinate /s/ from reactant to product and a distance /d/ from the line between them.
The method follows R. Goswami, "Two-dimensional RMSD projections for reaction path visualization and validation", /MethodsX/ (2026), [[https://doi.org/10.1016/j.mex.2026.103851][doi:10.1016/j.mex.2026.103851]].

The surface behind the band comes from the images of every iteration.
The default =--surface-type rbf= fits a thin-plate spline to their energies.
The =grad_= types, such as =grad_matern= and =grad_imq=, fit a Gaussian process (GP) to the energies and to gradients made from the force along the band.

* Usage

In a folder of eOn NEB output, with the =neb_*.dat= and =neb_path_*.con= files of each saved iteration:

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type profile -o neb_profile.pdf
rgpycrumbs eon plt-neb --plot-type landscape -o neb_landscape.pdf
#+end_src

Without =-o=, ~plt-neb~ opens the plot in a window instead of saving it.
=--input-dat-pattern= and =--input-path-pattern= take other file patterns.
=--start= and =--end= pick a slice of the sorted =.dat= files for the profile, with =--end= excluded.
If that slice is empty, or no file matches the pattern, the profile stops with =No profile data files found in the requested start:end range=.

* Library interface

#+begin_src python
from rgpycrumbs.eon import plot, plot_neb

# Job files, with the same settings as the command line
plot_neb(
    plot_type="landscape",
    con_file="neb.con",
    surface_type="grad_imq",
    plot_structures="crit_points",
    output_file="neb_2d.pdf",
    config="plot.toml",  # optional
)

# Live pyeonclient NEB after compute()
plot(neb, plot_type="profile", output_file="1d.pdf")

# ConFrame list from neb.path_frames()
plot(frames, kind="neb", plot_type="profile", output_file="1d.pdf")
#+end_src

The library calls turn on =RGPYCRUMBS_AUTO_DEPS= as the dispatcher does, unless it or =RGPKGS_AUTO_DEPS= is already set, or the rgpycrumbs configuration turns it off.
With it on, ~ensure_import~ installs a missing =jax= for the gradient surfaces, or a missing =xyzrender= for structure strips, into the uv cache.

* Plot files

=--config plot.toml= reads settings from a plot file in Tom's Obvious, Minimal Language (TOML).
Its =[shared]= section applies to ~plt-neb~, ~plt-min~ and ~plt-saddle~, and its =[neb]= section to ~plt-neb~ alone.
Two surface-fit keys exist only in this file: =auto_thin=, off by default, and =max_surface_points=.
With =auto_thin = true=, the fit takes at most =max_surface_points= points: the first, the last, and others evenly spaced between them.
The plot still draws every point.
[[file:plot_config.org][eOn plot TOML config]] lists all the keys.

* Key options

=rgpycrumbs eon plt-neb --help= lists every option with its default.

| Option | Default | Effect |
|--------+---------+--------|
| =--plot-type= | =profile= | =profile= or =landscape= |
| =--plot-mode= | =energy= | =energy= or =eigenvalue= |
| =--surface-type= | =rbf= | Surface fit for the landscape |
| =--project-path= / =--no-project-path= | on | Rotation into /s/ and /d/ |
| =--rc-mode= | =path= | Reaction coordinate of the profile: =path=, =rmsd=, =index= or =mw= |
| =--spline-method= | =hermite= | Profile curve: =hermite=, =spline= or =none= |
| =--energy-unit= | =eV= | =eV=, =kcal/mol= or =kJ/mol= |
| =--plot-structures= | =none= | Strip: =none=, =all= or =crit_points= |
| =--strip-renderer= | =xyzrender= | =xyzrender=, =ase=, =solvis= or =ovito= |
| =--rotation= | =auto= | Viewing rotation of the strip |
| =--perspective-tilt= | =0.0= | Off-axis tilt of the strip, in degrees |
| =--ira-kmax= | =1.8= | Factor on the IRA basis cutoff |
| =--mmf-peaks= / =--no-mmf-peaks= | on with a =climb= movie | Refinement frames on the landscape |
| =--show-evolution= | off | Earlier bands on the landscape |

* Climbing-image refinement and band evolution

The =--mmf-peaks= flag overlays the frames of a minimum-mode following (MMF) refinement on a landscape plot.
It reads the =climb= or =climb.con= movie that eOn writes into the folder named by =--peak-dir=, which defaults to the current folder.
Without either flag, the overlay turns on whenever that folder contains such a movie, and =--no-mmf-peaks= turns it off.

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type landscape --mmf-peaks --peak-dir climb_run/ -o neb_mmf.pdf
#+end_src

=--show-evolution= draws the bands of the earlier iterations, from their =neb_path_*.con= files, behind the final band of a landscape plot.

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type landscape --show-evolution -o neb_evolution.pdf
#+end_src

* Structure strips

=--plot-structures crit_points= renders the reactant, the saddle point and the product in a strip under the plot, and =all= renders every image.
Both read the structures from =--con-file=.

#+begin_src bash
rgpycrumbs eon plt-neb --plot-type profile --plot-structures crit_points --con-file neb.con \
  --energy-unit kJ/mol -o neb_profile_strip.pdf
#+end_src

=--strip-renderer= picks the renderer, and [[file:../../tutorials/rendering-backends.org][the rendering backends tutorial]] compares the four.
=--rotation auto=, the default, lets =xyzrender= orient each structure.
A rotation in the style of ASE, such as =--rotation "0x,90y,0z"=, fixes one view for every renderer.
=--perspective-tilt= tilts the view by a small angle, in degrees, so that atoms hidden behind others come into sight.
