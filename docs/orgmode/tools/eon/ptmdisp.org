* PTM displacement
~ptmdisp~ looks for interstitial atoms in a crystal and prints the indices of the atoms around them, to set up the list of atoms that eOn displaces.
It finds the atoms that do not match a crystal structure, face-centered cubic (FCC) by default, with the Polyhedral Template Matching (PTM) modifier of the ~ovito~ Python module.

.. click:: rgpycrumbs.eon.ptmdisp:main
   :prog: rgpycrumbs eon ptmdisp

#+END_EXPORT

** Usage
#+begin_src bash
rgpycrumbs eon ptmdisp structure.con --no-fcc-vacancy true
#+end_src

With ~--no-fcc-vacancy true~, a vacancy step splits the mismatched atoms into vacancy atoms and interstitials by their centrosymmetry.
The command then prints, on one line, the zero-based indices of the interstitials and of every atom within 5 Å of their center.
For a copper crystal of 108 atoms with one extra atom in an octahedral site, the line lists 39 indices: the extra atom and its 38 neighbors within 5 Å.
The dispatcher first writes a line that starts with =-->= to the same output, so drop that line before passing the indices on.

With the default ~--no-fcc-vacancy false~, the vacancy step is off and every mismatched atom counts as a vacancy atom.
The same crystal then gives an empty line, although the help text of the option says that ~true~ turns the step off.

With either value of the option, the command also writes a picture of the atoms within 5 Å to =selection.png= in the current folder.
With ~ovito~ 3.17, this picture needs a Vulkan driver, such as the Mesa software driver.
