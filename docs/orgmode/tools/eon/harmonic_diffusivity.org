* Harmonic diffusivity
Convert the same reactant and saddle vibration records used by
~harmonic-rates~ into HTST and qq-HTST log10 diffusivities (cm²/s) and
compare them with a user-supplied reference series. The geometric prefactor
is ``D = n λ² Γ / (2 d)`` with an explicit positive hop length ``λ``
(angstrom), path multiplicity ``n``, and lattice dimension ``d``.

#+BEGIN_EXPORT rst
.. click:: rgpycrumbs.eon.harmonic_diffusivity:main
   :prog: rgpycrumbs eon harmonic-diffusivity
   :nested: full
#+END_EXPORT

** Usage
#+begin_src bash
rgpycrumbs eon harmonic-diffusivity reactant.json saddle.json reference.csv \
  --hop-length 2.5 --path-multiplicity 12 --lattice-dimension 3
#+end_src

JSON records carry ~electronic_energy_eV~ and ~signed_wavenumbers_cm-1~
(project out rigid modes first). The CSV columns are
~inverse_temperature_1000_per_K~ and ~log10_diffusivity_cm2_per_s~.
Stdout repeats the inverse temperatures and reference values, then
~htst_log10_diffusivity_cm2_per_s~, ~htst_difference~,
~qq_htst_log10_diffusivity_cm2_per_s~, and ~qq_htst_difference~.

* Fixed-lattice instanton rates

A fixed-lattice LI calculation samples a periodic cell with a subset of
mobile atoms. The native solver level contains the absolute log flux, ring
temperature, bead count and fluctuation index. The native seed specifies
the ordered mobile indices, isotope masses and reactant energy. The minimum
spectrum supplies one positive frequency per mobile Cartesian coordinate
in that same fixed lattice.

#+begin_src bash
rgpycrumbs eon lattice-instanton-diffusivity levels.jsonl reactant.json seed.json \
  --hop-length 1.17 --path-multiplicity 4 --lattice-dimension 3
#+end_src

The JSON result gives =log10_hop_rate_per_s= and
=log10_diffusivity_cm2_per_s=. A single retained negative mode and matching
reactant electronic zeros are required. Each positive mode contributes
the finite-bead factor $[2\sinh(P\,\mathrm{asinh}(\beta\hbar\omega/(2P)))]^{-1}$
to the reactant partition. Rigid translations and rotations of the full cell
are absent because the lattice contains fixed atoms.
