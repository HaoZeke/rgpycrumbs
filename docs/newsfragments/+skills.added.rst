``skills/`` holds three task guides, each a ``SKILL.md`` with scripts that check what it says against the code. ``rgpycrumbs-cli`` covers how a command maps to a script, what the script installs, when the active interpreter is used instead of uv, pinning versions, and the listed commands that are library modules. ``rgpycrumbs-neb-plots`` reads barriers from an eOn NEB run and draws its profile and landscape, and ``rgpycrumbs-add-tool`` covers adding a command. ``python scripts/skills/run_skills.py`` checks every guide and runs its scripts.
