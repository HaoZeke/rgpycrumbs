The gradient-enhanced Matern 5/2 covariance and its prediction and variance query rows use the cancellation-free derivative ``-dk/dr / r = (5 / (3 l^2)) (1 + u) exp(-u)`` instead of differentiating the kernel with JAX. At a repeated input the autodiff Hessian lost several percent in float32 and left the covariance indefinite, so ``GradientMatern`` predictions on a 30-point bowl were off by up to 45.4.
